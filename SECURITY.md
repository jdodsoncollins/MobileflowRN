# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository. Include the affected version, reproduction steps, impact, and any suggested mitigation.

You should receive an initial response within 7 days. Maintainers will coordinate disclosure after they validate and address the report.

## Scope

Security reports may cover this Expo application, its OAuth flow, token handling, Webflow action confirmation, or the local native planner. Reports about Webflow or Expo infrastructure should go to those vendors.

Never include production tokens, client secrets, private site content, or personal data in a report.
